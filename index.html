Understanding / 案件理解

届けたい相手は、ふたり。
求められているのは、誠実さです。

今回のサイトは、派手な演出で惹きつけるものではなく、見る人が「自分たちにも関係がある」と 気づける構成が核心だと理解しています。読む人が異なれば、必要な情報の深さも異なります。

首長など意思決定層の方へ

短時間で全体像をつかみたい方には、ビジョンと3地域の事例を端的に見せる動線が必要です。 1画面目の動画から事例・活動報告へ自然に導く、PLATEAU型の構成を踏襲します。

自治体・地元企業の担当者へ

「自分たちにもできそうか」を判断するには、分野別に絞り込める事例一覧や、 詳細な活動報告・コラムが欠かせません。記事が増えても崩れない型を用意します。

01

このサイトの成功は、閲覧数やデザインの派手さでは測れません。「うちでもやってみたい」という 問い合わせにつながるかどうかが唯一の指標だと理解しています。だからこそ、信頼感・誠実さ・分かりやすさを デザインの判断軸として一貫させることを、Kairosはお約束します。

Value / Kairosが提供できること

WordPressで運用しやすい、
崩れないデザインシステムを。

エンジニアの方が迷わずコーディングできること、そして担当者様が記事を更新し続けても 体裁が崩れないこと。この2点を軸に、Figma上で完結する設計をご提供します。

VALUE 01

二者の視点を両立する情報設計

首長層向けの「概要を掴む動線」と、担当者向けの「深掘りできる動線」を 1つのトップページ内に共存させ、どちらの読み手も迷わせない構成にします。

VALUE 02

Figma Variables による一元管理

色・文字・余白はすべてVariablesで定義し、ボタン・見出し・カードなどの コンポーネントはWordPressブロック1つ分を目安に整理して納品します。

VALUE 03

記事が増えても崩れないテンプレート

事例・活動報告・コラムの一覧／詳細は、オートレイアウトを用いた 可変テンプレートとして設計し、文字量や写真点数の増減に強い構造にします。

VALUE 04

PLATEAU型トップページの再構築

1画面目の動画から事例・活動報告へ滑らかに誘導する構成を、 御社の取り組みの温度感に合わせて端正にアレンジしてデザインします。

VALUE 05

3種のフォームを1つの型で

お問い合わせ・資料ダウンロード・ウェビナー申込を、プラグインで再現可能な 見た目に揃えたうえで、入力しやすい1つのフォームテンプレートとして設計します。

VALUE 06

継続を見据えた拡張性

2〜3月のページ追加や、今後の別案件も見据え、 後から要素を足しても破綻しないコンポーネント構成を意識して設計します。

Process / 進め方とスケジュール
